# AccountDock 1.0.0

Initial AccountDock release baseline.

## Included

- Unified Claude Code and Codex account management and switching.
- Isolated managed Codex homes and active-system credential promotion.
- Combined provider usage, activity, model, and API-equivalent cost views.
- Configurable menu-bar modules with usage bars or numeric percentages.
- Cost history initially limited to seven days with week-by-week expansion.
- Native launch-at-login support.
- GitHub release checks that provide a user-reviewed safe install command.
- macOS CI, Developer ID signing, notarization, package checksums, and GitHub
  release publishing for version tags.

No release has been pushed or published from this workspace.
